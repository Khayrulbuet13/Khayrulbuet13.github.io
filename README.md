# Khayrul Islam's Personal Website

This repository contains the source code for my personal website. The site is built with [Hugo](https://github.com/gohugoio/hugo) and uses a customized version of the [PaperMod theme](https://github.com/adityatelange/hugo-PaperMod) that I've modified to create a minimalist academic profile. The website is hosted on [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages) and can be accessed at [khayrul.me](https://khayrul.me).

## About Me

I am a Ph.D. candidate in Mechanical Engineering at Lehigh University, graduating in May 2025. My research as a Graduate Research Assistant at the Bio-Nano Interface Lab has centered on advancing computer vision techniques for medical imaging and developing machine learning architectures for real-time biomedical applications.

## Website Features

- Personal profile and biography
- Academic publications
- Research projects
- Interactive CV
- Contact information
- Blog integration with Medium
- Custom chatbot (AskKhayrul) for visitors

## Technical Implementation

This website uses Hugo v0.135.0 and employs GitHub Actions for automatic deployment. The site maintains excellent performance scores on both mobile and desktop platforms.

## Local Development

To run this site locally:
1. Clone the repository
2. Ensure Hugo is installed (`brew install hugo` on macOS)
3. Run `hugo server` to launch the development server
4. Access the site at http://localhost:1313

## Deployment

The site is automatically built and deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the main branch.
